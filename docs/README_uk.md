## Вступ

LMCL — це відкритий, кросплатформний лаунчер для Minecraft, який підтримує керування модами, налаштування гри, встановлення модлоадерів (Forge, NeoForge, Cleanroom, Fabric, Legacy Fabric, Quilt, LiteLoader та OptiFine), створення модпаків, налаштування інтерфейсу та багато іншого.

LMCL має чудові кросплатформні можливості. Він працює не лише на різних операційних системах, таких як Windows, Linux, macOS і FreeBSD, а й підтримує різні архітектури процесорів, такі як x86, ARM, RISC-V, MIPS і LoongArch. Ви можете легко насолоджуватися Minecraft на різних платформах за допомогою LMCL.

Щодо підтримуваних систем і архітектур процесорів дивіться [цю таблицю](PLATFORM.md).

## Внесок

LMCL — це відкритий проект, який розвиває спільнота. Ми раді внескам у код і пропозиціям.

Ви можете допомогти розробці LMCL такими способами:

- Повідомляйте про помилки або пропонуйте нові функції, [створивши issue](https://github.com/Axolotl-Org/LMCL/issues/new/choose) на GitHub.
- Додавайте код, зробивши fork репозиторію на GitHub і [надіславши pull request](https://github.com/Axolotl-Org/LMCL/compare).

Перед участю прочитайте [посібник для учасників](./Contributing.md), який містить таке:

- [Як зібрати і запустити LMCL з вихідного коду](./Contributing.md#build-lmcl)
- [Як змінювати поведінку LMCL за допомогою параметрів налагодження](./Contributing.md#debug-options)
