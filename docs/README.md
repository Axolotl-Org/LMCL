## Introduction

LMCL is an open-source, cross-platform Minecraft launcher that supports Mod Management, Game Customizing, ModLoader Installing (Forge, NeoForge, Cleanroom, Fabric, Legacy Fabric, Quilt, LiteLoader, and OptiFine), Modpack Creating, UI Customization, and more.

LMCL has amazing cross-platform capabilities. Not only does it run on different operating systems like Windows, Linux, macOS, and FreeBSD, but it also supports various CPU architectures such as x86, ARM, RISC-V, MIPS, and LoongArch. You can easily enjoy Minecraft across different platforms through LMCL.

For systems and CPU architectures supported by LMCL, please refer to [this table](PLATFORM.md).

## Contributing

LMCL is a community-driven open-source project, and everyone is welcome to contribute code or provide suggestions.

You can contribute to LMCL development in the following ways:

- Report bugs or request features by [creating an issue](https://github.com/Axolotl-Org/LMCL/issues/new/choose) on GitHub.
- Contribute code by forking the repository on GitHub and [submitting a pull request](https://github.com/Axolotl-Org/LMCL/compare).

Before contributing, please read the [Contributing Guide](./Contributing.md), which includes the following:

- [How to build and run LMCL from source](./Contributing.md#build-lmcl)
- [Adjusting LMCL behavior using debug options](./Contributing.md#debug-options)
