### 概敘

LMCL 者，開源之礦藝啟器也。善理改囊，可自定遊戲，自動裝設 Forge、NeoForge、Cleanroom、Fabric、Legacy Fabric、Quilt、LiteLoader、OptiFine 諸改囊，亦能制改囊集，界面隨心易之。

LMCL 跨域廣矣。Windows、Linux、macOS、FreeBSD 諸常見械綱，x86、ARM、RISC-V、MIPS、LoongArch 諸算器架構，皆可運行。
憑此器，可遊《礦藝》於諸機之間，無礙也。  

欲知 LMCL 所支平臺，詳觀[此表](PLATFORM_zh_Hant.md)。

## 與貢

LMCL 乃社群共驅之開源項目，迎諸君獻碼或建言。

參與之道如下：

- 於 GitHub 上[創建 Issue](https://github.com/Axolotl-Org/LMCL/issues/new/choose)，以報謬誤或求功能。
- 於 GitHub 上 Fork 倉庫，並[提交 Pull Request](https://github.com/Axolotl-Org/LMCL/compare)，以貢代碼。

貢獻之前，請閱[貢獻指南](./Contributing_zh_Hant.md)，中含：

- [如何自源碼構建並執行 LMCL](./Contributing_zh_Hant.md#構建-lmcl)
- [以勘誤選項調整 LMCL 之行為](./Contributing_zh_Hant.md#除錯選項)
